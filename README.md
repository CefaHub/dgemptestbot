# ✨ DOLCE EMPIRE — самостоятельный Telegram K-pop Tycoon & Gacha Bot

**Это отдельный бот и отдельный GitHub-репозиторий.** Никаких файлов из DolceGllitBot не требуется.

## Возможности версии 1.0

- 🎰 86 K-pop карт: LE SSERAFIM, IVE, aespa, TWICE, ITZY, BLACKPINK, i-dle, NewJeans; 6 редкостей, сохранение каждой копии и серийный номер.
- 🆓 1 бесплатная крутка в час, запас до 3; гаранты Epic/Legendary/Mythic через 10/40/150 круток без такой редкости.
- 💸 Платная крутка от 2 000 монет, затем **8 × пиковый доход студии/час**, плюс 15% за каждую дополнительную платную крутку за сутки (UTC). Премиум ×4, нет Common и 70% фокус на группе недели в рамках выбранной редкости.
- 🏢 Студия: 3–8 активных слотов; накопление монет офлайн максимум 12 часов между сборами. Смена состава не обнуляет начисленное.
- 🃏 Прокачка до уровня 50; пробуждение до 5 раз с расходом копий; улучшения с возрастающей ценой.
- 📚 Альбомы по эрам и группам, неизгладимое открытие карт, +5% за полный сет (до +20%).
- 🤝 Двухэтапные обмены картами и монетами: предложение → принятие → подтверждение инициатором.
- 🛒 Маркет объявлений по фиксированной цене, налог 5%, атомарная покупка.
- 🎁 Ежедневный бонус и 3 ежедневных задания; 🏆 4 вида рейтингов.
- 🎨 Рисованные процедурные рамки с возможностью подставить **свои** изображения айдолов в assets/idols (в репозитории реальных фотографий нет).
- 🔐 Экономика на сервере, транзакции PostgreSQL и проверки владельца карточки, блокировка рыночных предметов, журнал финансов.

## Быстрый запуск на ПК (Windows PowerShell)

1. Создай **отдельного бота** в [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Установи Python 3.11+ и Git (для хостинга через Git нужен только Git).
3. В корне проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BOT_TOKEN="ТВОЙ_ТОКЕН_ОТ_BOTFATHER"
python -m dolce_empire.bot
```

Для локальной игры используется SQLite: `data/empire.db`, он исключён из Git. **Не удаляй его, иначе потеряешь прогресс**.

## Bothost / другой Python-хостинг

- Создай **нового** бота в панели (старый DolceBot не меняй).
- Добавь Git-репозиторий с этим проектом.
- Start command: `python -m dolce_empire.bot` (если панель принимает только `python main.py`, у нас есть файл `main.py`).
- Установи зависимости из `requirements.txt`.
- В переменных окружения задай `BOT_TOKEN` из BotFather.
- `DATABASE_URL` необязателен для локального запуска, но **на хостинге нужен постоянный диск для SQLite** или внешняя PostgreSQL. Без этого база может исчезнуть при переразвёртывании.
- Для PostgreSQL задайте `DATABASE_URL=postgresql+asyncpg://USER:PASSWORD@HOST:PORT/DB`.
- Не вставляй настоящий токен в Python-код и не загружай `.env` на GitHub.
- Для нескольких экземпляров бота используйте PostgreSQL, **запускайте только один экземпляр long polling** (иначе Telegram Conflict). SQLite и несколько реплик не поддерживаются.

## Docker Compose (PostgreSQL)

Создай `.env` **только локально**:

```
BOT_TOKEN=...настоящий_токен...
POSTGRES_PASSWORD=придумай_сильный_пароль_без_спецсимволов_URL
```

Запусти `docker compose up -d --build`.

## Основные команды

`/start`, `/help`, `/me`, `/roll`, `/studio`, `/claim`, `/cards`, `/find ИМЯ`, `/card ID`, `/equip ID SLOT`, `/unequip ID`, `/upgrade ID`, `/awake ID`, `/expand`, `/album`, `/daily`, `/quests`, `/market`, `/sell ID PRICE`, `/unsell ID`, `/buy ID`, `/trade`, `/trades`, `/top`.

**Обмен:** ответь на сообщение второго игрока:
`/trade 123 456 0 500` — ты отдаёшь экземпляр #123, хочешь его #456 и 500 монет; оба видят условия, второй подтверждает, затем ты завершаешь. Если пишешь в личке без reply: `/trade USER_ID 123 456 0 500`.

**Картинки:** положи JPEG/PNG/WebP в `assets/idols/` с именем `id` карты из `data/catalog.json` (например `le-sserafim-eunchae-crazy.jpg`). Без файла карточка красиво оформляется абстрактным артом. Убедись в разрешении на использование фотографий и логотипов.

## Сохранность данных

PostgreSQL — рекомендуется для продакшна и торговой системы. `create_all` создаёт таблицы в пустой БД; **для будущего изменения схемы потребуется миграция**, не сбрасывай таблицы для обновлений.

Карты защищены проверками владения, обмены завершаются одной транзакцией, лоты атомарны. Все перемещения монет идут через `ledger`. Для серьёзной многопользовательской нагрузки отдельно стоит провести нагрузочное тестирование и независимый аудит.

## Ограничения 1.0

- **Полноценные аукционные ставки и мировой босс** ещё не реализованы; рынок сейчас с фиксированными ценами.
- Сезоны: премиум-баннер автоматически фокусируется на одной группе недели; отдельные временные событийные карты и индивидуальные расписания ивентов пока не реализованы.
- Косметические рамки по достижениям, друзья и престиж запланированы, но ещё не реализованы.
- Встроенные фотографии известных людей не распространяются.
